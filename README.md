# OroTsukuIndex

> An archive dedicated to the **月蛇月** ship from *Onmyoji* (阴阳师手游).

The archive is available through the web interface:
**[SheYue99](https://phe2i.github.io/OroTsukuIndex/)**

Currently provides:

* Skin / merchandise / costume records
* Random skin selection for drawing-topic purposes
* In-game 3D model viewing

---

# About

**OroTsukuIndex** is a fan-made archival project for collecting and organizing information related to the **月蛇月** ship and its two characters from *Onmyoji* (阴阳师手游):

* 🐍 Orochi (八岐大蛇)
* 🌙 Tsukuyomi (月读)

This project is an ongoing archive. Information may be added, corrected, reorganized, or expanded over time.

The archive may include:

* Official game content
* Official merchandise
* 3D models
* Community-preserved information

Where possible, original sources and relevant references are recorded alongside the archived information.

Some of the collected information is also available in this [Google Document](https://docs.google.com/document/d/1HqaYiDbOqpp6UyVHBzZM5eC6ugqhWbtIgfyjqP4Un2U/preview?tab=t.0).
